# Fake News Detection using Machine Learning

This project detects fake and real news using NLP and Machine Learning techniques.

## Features
- Text cleaning
- TF-IDF vectorization
- Model training and evaluation
- Fake/Real news prediction

## Technologies Used
- Python
- Scikit-learn
- NLP (TF-IDF)

## Project Structure
- clean_text
- prepare_data
- train_model
- evaluate_model
- predict_news

## Output

The model predicts whether the given news is Fake or Real.
