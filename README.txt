# Fake News Detection using Machine Learning

This project detects whether a news article is Fake or Real using
Machine Learning and Natural Language Processing (NLP).

## Problem Statement
Fake news spreads misinformation rapidly on social media and news platforms.
This project helps identify fake news automatically using machine learning.

## Features
- Text cleaning and preprocessing
- TF-IDF vectorization
- Machine learning classification
- Predicts whether news is Fake or Real

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Natural Language Processing (NLP)

## Project Files
- clean_text.py : Cleans and preprocesses text
- load_data.py : Loads fake and real news data
- prepare_data.py : Prepares training and testing data
- train_model.py : Trains the ML model
- evaluate_model.py : Evaluates model accuracy
- predict_news.py : Predicts news type

## How to Run the Project
1. Open terminal in project folder
2. Run the following commands:

python load_data.py  
python prepare_data.py  
python train_model.py  
python evaluate_model.py  
python predict_news.py  

## Model Accuracy
The model achieves around 98% accuracy on test data.
